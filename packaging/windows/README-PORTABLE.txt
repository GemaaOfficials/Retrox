ReEditX Portable for Windows
============================

How to launch
1. Extract this ZIP completely into a normal folder. Do not run start.bat from inside the ZIP preview.
2. Open the extracted ReEditX folder.
3. Double-click start.bat.
4. Wait for the ReEditX Studio window to open.

Important
- Keep every file and folder from this ZIP together.
- Do not move ReEditX.exe or the resources folder separately.
- No Node.js installation is required; the app includes its local runtime.
- If Windows shows a security warning, only continue if you downloaded this ZIP from the official GemaaOfficials/Retrox GitHub release.
- The app runs its editing engine locally on your PC.
